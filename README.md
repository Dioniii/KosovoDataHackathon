# KosovoDataHackathon

**Kosovo Property & Investment Screener** — a one-day hackathon project that helps a diaspora Kosovar pick a starting point for research (not financial advice) into which Kosovo region is worth a closer look, either to buy residential property or to invest in a small business, by combining regional investment, tourism, housing, and business-sector data from ASKdata and the World Bank into a single browsable dataset. The data pipeline lives in `pipeline/fetch.py`; run it with `python pipeline/fetch.py` from the repo root (requires the `requests` package — `pip install requests`) to regenerate `pipeline/data.json`, or use the committed `pipeline/sample_data.json` for local development against the same shape (documented in `docs/DATA_CONTRACT.md`) before the real pipeline is wired up.
